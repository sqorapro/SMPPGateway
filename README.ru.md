# SMPP Gateway — USB Modem SMS & Call

*[English version](README.md)*

Десктопное приложение для Windows: SMPP-сервер, массовая SMS-рассылка и массовые звонки через USB-модемы (Huawei E173/E3372).

## Возможности

- **SMPP 3.4 сервер** — принимает запросы от удалённого сервера, отправляет SMS через подключённые модемы
- **Массовая SMS-рассылка** — загрузка базы номеров (CSV/TXT/Excel), текст сообщения, отправка через все модемы
- **Массовые звонки** — загрузка базы номеров + аудиофайл (WAV), звонки через модемы E173 с воспроизведением аудио
- **Поддержка кириллицы** — UCS-2 кодирование
- **Длинные SMS** — склейка до 4 частей (UDH)
- **Логи** — SQLite база с историей всех SMS и звонков

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Настройка

### 1. Вкладка "Модемы"
- Нажмите "Сканировать порты" для обнаружения USB-модемов
- Выберите порт и нажмите "Подключить выбранный"
- Столбец "Голос" показывает, поддерживает ли модем голосовые вызовы (E173 — да, E3372 — нет)

### 2. Вкладка "SMPP сервер"
- Укажите хост (0.0.0.0 для всех интерфейсов), порт (по умолчанию 2775)
- Задайте System ID и пароль
- Нажмите "Запустить SMPP сервер"
- Настройте ваш удалённый сервер на подключение к этому SMPP серверу (через DynDNS домен)

### 3. Вкладка "Массовые звонки"
- Загрузите базу номеров (CSV/TXT — один номер на строку, или Excel)
- Выберите WAV-аудиофайл
- Задайте таймаут звонка
- Нажмите "Начать обзвон"
- Звонки выполняются параллельно через все модемы с поддержкой голоса (E173)

### 4. Вкладка "SMS рассылка"
- Загрузите базу номеров
- Введите текст сообщения
- Нажмите "Начать рассылку"
- SMS отправляются через все подключённые модемы

### 5. Вкладка "Логи"
- Просмотр истории всех SMS и звонков из SQLite базы

## Требования

- Windows 10/11
- Python 3.8+
- USB-модемы Huawei E173 (гололс + SMS) и/или E3372 (только SMS)
- SIM-карты с активными SMS и голосовыми услугами
